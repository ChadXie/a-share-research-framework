A股投研统一执行框架
把"看一只股票"变成可复用的流水线

一份纯 Markdown 指令文件驱动的投研框架：将"分析一只股票 / 一个板块 / 一次行情研究"固定成一条可复用、可复核、带风控闭环的 8 阶段流水线。原生为 WorkBuddy 设计，但指令是纯文本，可直接装进 Codex、Claude Code、Cursor、Windsurf、Cline、Roo Code、GitHub Copilot 等任何读取"指令文件"的 Agent——一份框架，多处通用。

⚡ 一键安装 📈 看示例（中际旭创） ⭐ GitHub 仓库

为什么需要它

零散的"帮我看看 XX 股票"往往得不到一致、可复用的产出。本框架强制四件事：

① 角色分工

数据员 → 情报员 → 行业研究员 → 投资委员会 → 人工裁决 → 盯盘风控员 → 复盘，每个角色对应具体 Skill，不再凭感觉。

② 多空对冲

UZI 多视角委员会强制产出四要素（多头 / 反方 / 争议 / 失效），刻意制造反方叙事，避免单边乐观。

③ 人机协作

WorkBuddy 负责证据链、数据核验与风险收益比计算，最终买卖由使用者本人拍板，不替你决策。

④ 闭环复盘

跟踪结果回灌筛选规则，越用越准——这是"框架"而非"一次性报告"的关键。

📈完整示例：中际旭创（300308）

以 AI 算力链光模块龙头为例，演示框架的完整产出。下方为 UZI 委员会四要素缩略，完整可视化见示例文件。

🟢 多头逻辑

  • 业绩兑现最硬：2026Q1 营收 +192%、净利 +262%
  • 英伟达 1.6T 光模块份额约 80%，缺口订单排至 2027
  • PEG≈0.45，按 2026E 净利约 220 亿看似便宜

🔴 反方观点

  • PE(2025)≈96x，较高位已回撤约 37%
  • AI 资本开支见顶风险（云厂 FCF 转负、穆迪表外债警告）
  • 客户集中（前五大 81.9%）、存货 +53% 至 194 亿

🟡 争议变量

  • 2027 年 1.6T 真实价格 / 需求指引尚未被证实
  • 1.6T 渗透节奏与 ASP 下滑斜率

🟣 失效条件

  • 大客户下修 2027 capex
  • 中报毛利率跌破 28% / 存货减值
  • 放量跌破 800 元
📌 结论：中长期看多、短线不追高——"三高"状态（高拥挤 / 高波动 / 高估值）下不建议情绪高位追涨。

⚡安装（跨 Agent 通用）

本框架是纯 Markdown 指令文件，可装进任何会读取"指令文件"的 Agent。下面给出主流 Agent 的安装步骤。

🌐 跨 Agent 通用原理

框架核心是一份纯文本指令（SKILL.md），不绑定 WorkBuddy 专有机制。把它的内容放进对应 Agent 的"系统指令 / 记忆文件"，即生效。

Agent指令文件位置加载方式
WorkBuddy~/.workbuddy/skills/a-share-research-framework/SKILL.md按意图自动加载
Claude Code~/.claude/CLAUDE.md 或 ./CLAUDE.md每次会话自动遵循
Codexcodex.md / AGENTS.md（项目根）会话内自动遵循
Cursor / Windsurf / Cline / Roo / CopilotAGENTS.md（仓库根）会话开始读取

① WorkBuddy

git clone https://github.com/ChadXie/a-share-research-framework.git \
  ~/.workbuddy/skills/a-share-research-framework

刷新 WorkBuddy 后，出现"分析股票 / 行情 / 候选池 / 多空 / 盯盘 / 复盘"等意图即自动加载。

② Claude Code

# 全局常驻：追加到 CLAUDE.md
cat a-share-research-framework/SKILL.md >> ~/.claude/CLAUDE.md

# 或做成斜杠命令（项目级）
# 创建 .claude/commands/research.md，首行写：
#   analyze a stock using the 8-stage research framework: $ARGUMENTS
# 下面贴入 SKILL.md 正文，之后用 /research 中际旭创 触发

③ Codex（OpenAI）

# 项目根写入 codex.md（或 AGENTS.md）
cp a-share-research-framework/SKILL.md ./codex.md
# cp a-share-research-framework/SKILL.md ./AGENTS.md

④ Cursor / Windsurf / Cline / Roo / GitHub Copilot 等

# 仓库根创建 AGENTS.md，写入 SKILL.md 全文
cp a-share-research-framework/SKILL.md ./AGENTS.md

这些工具在会话开始读取 AGENTS.md，框架即生效；一处写入，所有支持该约定的 Agent 通用。

ℹ️ 若目标 Agent 对 YAML frontmatter 敏感，可删除 SKILL.md 顶部 --- 之间的 frontmatter，仅保留正文。
